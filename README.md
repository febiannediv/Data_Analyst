### 02. Car Showroom Sales Analysis

![Python](https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white)

> Case study: sales data from a car showroom with **10 branches**. The goal is to find which branch should add stock for which car category.

**What I analyzed**
- Data size (number of rows and columns) using `df`
- Number of transactions per car category, with a bar chart
- Branch with the most transactions
- Data quality checks: missing values and duplicate rows
- Which **branch and car category combination** generates the highest revenue (`total_sales`)

**Business value:** the last analysis helps decide which branch needs extra stock in which car category.

**Key insights:** [1-2 temuan utama dengan angka]

### 04. Excel Analysis

![Excel](https://img.shields.io/badge/Excel-217346?style=flat-square&logo=microsoftexcel&logoColor=white)

> Spreadsheet exercises on payroll and sales data using lookup formulas, conditional logic, and a pivot table.

**What I did**
- `VLOOKUP` to fill basic salary, allowance, and transportation from the salary table
- `HLOOKUP` to fill tax deduction from the tax deduction table
- `IF` to mark sales as "Tercapai" when turnover is at least 1,000,000
- Pivot table on the "Bill all" sheet by `NAMA BARANG` to summarize QTY, price, discount, and net total (answers in the "Jawaban PIVOT" sheet)

**Key insights:** [1-2 temuan utama, jika ada]
